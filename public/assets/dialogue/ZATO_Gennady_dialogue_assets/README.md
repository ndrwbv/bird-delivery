# Геннадий — ассеты для диалоговой сцены «ЗАТО Солнечный»

Пакет составлен **из ранее созданных изображений**. Новых изображений не генерировали.

## Содержимое
- `character/gennady/idle.png` — основное состояние.
- `character/gennady/talk.png` — разговор.
- `character/gennady/blink.png` — моргание.
- `character/gennady/smile.png` — улыбка.
- `character/gennady/angry.png` — раздражение.
- `reference/approved_ui_reference.png` — **утверждённый пользователем пример UI**; это референс, **не спрайт и не готовый интерфейс**.
- `optional/hallway_background_draft.png` — ранее сгенерированный черновой фон, можно заменить видом из игры.
- `optional/old_animation_demo.gif` — старое демо для просмотра ритма, не использовать как игровой ассет.
- `manifest.json` — пути к файлам, состояния анимации и тестовый диалог.
- `PROMPT_FOR_AGENT.md` — готовое задание агенту.

## Технические ограничения
- Спрайты RGBA 500×555, **поясные**, ноги намеренно не представлены (как на скриншоте с интерфейсом).
- Руки и колбаса внутри прямоугольника каждого спрайта. **Не обрезать повторно автоматически по bbox непрозрачных пикселей** — это может вызвать смещение при переключении состояний.
- Из-за генеративных различий между состояниями силуэт и лицо немного меняются. Это прототип: переключать короткими фазами, не пытаться делать плавный morphing между целыми спрайтами.
- Никакие картинки из этого архива не надо вручную растягивать на весь экран. Сцена строится из отдельных слоёв и настоящих UI-компонентов.
