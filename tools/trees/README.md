# Зимние деревья — как собрать

Голые кроны со снегом (берёза ×2, тополь, клён, липа, рябина, дерево аллеи) — скриптом в Blender без окна. Правила
(что видно когда, цена) — docs/CAREER.md «Деревья и кусты» → «Зимой — голые кроны в снегу».

1. Модели в игру и картинки для проверки:
   `/opt/homebrew/bin/blender -b --factory-startup -P wintertrees.py -- ../../src/game/wintertrees.data.js /tmp/wt`
   (из этой папки; вторая папка — по картинке на модель: `<имя>_0.png` сбоку, `<имя>_1.png` снизу-сбоку). Печатает
   треугольники, без прутьев и сколько граней в снегу.
2. Как устроено: на поверхности кроны-«яйца» (размеры — как у летней кроны в trees.js) — точки-концы прутьев (спираль
   Фибоначчи); точки собраны в кучки — сук на кучку, ветка на подкучку, прут на точку. Сечение: ствол — квадрат, сук и
   ветка — ромб, прут — треугольник вершиной вверх; каждая ветка сужается в точку. Грань с нормалью выше 0,3 — снег.
   Blender сваривает совпавшие вершины (общие вершины в файле).
3. Части: 0 — ствол, 1 — сук (видны всегда), 2 — ветка, 3 — прут (вид 7 в склейке: видны, когда облетела листва).
   Цвета частей по породам — `TREE.WINTER.COL` в trees.js; деревья дворов — lawnprops.js (`ywin`, `ywinb`).
4. Новая порода или форма — функция в разделе «породы» и строка в `MODELS`; в trees.js — вызов `winterTree` у породы.
5. Проверка: `npm run probe -- --size=deck --q="season=2.5" --shot=out.png` (сравнить — с `&nowt`); память телефона —
   `npm run check -- --only=build-web,memory-phone --serial`.
