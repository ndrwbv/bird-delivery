# Звуки — папка для автора

> Музыка (треки меню, дня, ночи, конца смены) — отдельно: [MUSIC.md](MUSIC.md), папка `public/music`.

С 09.10.2026 (М2) каждый звук игры можно заменить своим файлом. Файла нет — звучит как раньше
(синтез в коде). Код — `src/game/sfx.js` (файлы и звук в пространстве), `Snd` в `game.js` (шины и синтез),
мотор — `src/game/motor.js`.

## Как добавить звук

1. Положить файл в папку **`public/sfx`** с именем звука из таблицы ниже: `coin.ogg`, `crash-heavy.ogg`.
2. Обновить страницу (в dev — F5; в сборке — пересобрать). Всё, игра берёт файл вместо синтеза.
3. Проверить, что имя без опечатки: **`npm run sfx:index`** — таблица «из файлов / синтез», а файлы с
   неизвестным именем — отдельным списком «НЕИЗВЕСТНЫЕ» (игра их не возьмёт).

**Несколько вариантов одного звука** — номер через дефис: `coin-1.ogg`, `coin-2.ogg`, `coin-3.ogg`.
Каждый раз играет случайный, и каждый проигрыш чуть выше или ниже (±5 %) — удары не звучат одинаково.
Можно и без номера у одного и с номерами у других — всё, что до «-цифры», считается одним звуком.

**Запасные имена.** Некоторые звуки ищут сначала точное имя, потом запасное. Удары (с М4 — слоями,
раздел «Удары слоями» ниже): тело `hit-wall-heavy` → старое `crash-heavy` → `crash`, `hit-wall-mid` /
`-light` → `crash-light` → `crash`; у забора запасное — `fence`, у человека — `hit-person`, у бака — `clank`.
Положил один `crash.ogg` — он на все удары о стену, машину, столб и дерево (тогда хруст металла и низкий
«бум» не добавляются — в старом файле они уже есть).

## Формат

- **.ogg** (лучше всего: маленький, играет везде), можно **.mp3** и **.wav** (.m4a, .webm, .flac — тоже).
  Один звук — в одном формате, не кладите `coin.ogg` и `coin.mp3` вместе: это станут два варианта.
- Моно, 44,1 или 48 кГц. Короткие: удар, щелчок — до 1 с; гром, «дом унесло» — до 4 с.
- **Громкость:** пик около **−3 дБ** (нормализовать в редакторе). Игра сама делает файл примерно
  как синтез (×0,45); если одно имя громче или тише остальных — скажите, поправим одно число
  (`GAIN` в `sfx.js`). Удары, гром и хлопки выхлопа ещё тише-громче по силе в игре.
- Без тишины в начале — иначе звук «опаздывает».
- Сломанный файл игра не играет: звучит синтез, ошибка — в `__dlv.Snd.SFX.STATS.errors`.

Как это устроено: при сборке (и в dev на каждый запрос) из папки строится список `sfx/index.json` —
игра читает только его и не стучится за каждым именем (никаких 404). Работает в браузере, в Стиме
(Электрон) и на Яндексе. Сами файлы скачиваются и раскодируются один раз, после первого касания.

## Громкость: три ползунка и звук в мире

- **Настройки → звук:** вкл / выкл (M, R3) и три ползунка 0—100 %: **музыка** (треки — папка `public/music`,
  всё про музыку — [MUSIC.md](MUSIC.md); нет ни одного трека — у ползунка пометка «скоро»), **звуки** (всё, что в таблице, кроме мотора) и **мотор** (гул мотора и звуки с пометкой «мотор»
  ниже). Подробно — [CAREER.md](CAREER.md) «Главное меню, пауза и настройки».
- **Звук в мире** (в таблице — «в мире») слышно от того места, где он случился: чем дальше от своей
  машины, тем тише, дальше «слышно до» — тишина; слева — в левом ухе, справа — в правом (по камере).
  Рядом с машиной (до 5 м) — по центру и в полную силу. Остальные — «в машине»: по центру, всегда.
- `?mute` в адресе (автопроверки, probe) — без звука совсем: и синтез, и файлы, и мотор, и музыка.

## Удары слоями (М4)

С 09.10.2026 удар машины — не один звук, а **несколько слоёв сразу**: «бум» того, во что въехал (тело),
хруст своего кузова, низкий удар аварии, звон стекла и стук отлетевших деталей. Чем сильнее удар — тем
больше слоёв и громче. Код — `src/game/impact.js`. Ползунок «звуки», `?mute` глушит всё.

**Сила** — скорость удара «в лоб» (по нормали к препятствию):

| сила | скорость удара | слои |
|---|---|---|
| **тычок** (`light`) | 2,5—8 м/с (9—29 км/ч) | тело |
| **средний** (`mid`) | 8—15 м/с (29—54 км/ч) | тело + хруст кузова |
| **авария** (`heavy`) | 15 м/с и быстрее (с этой силы удар о стену бьёт сердца) | тело + хруст кузова + низкий «бум» |
| + в любой силе | если от удара треснуло / разбилось стекло или фара | + звон стекла |
| + потом | отлетевшая деталь (бампер, крышка, зеркало, колпак) падает на асфальт | + стук обломков на каждый отскок |

Громкость тела: тычок 45—70 %, средний 70—90 %, авария 90—100 % (растёт внутри ступени). Медленнее 2,5 м/с — тихо.

**Материал** — во что въехал (тело звучит по-своему):

| материал | что это в игре | тело: тычок / средний / авария | хруст кузова | «бум» |
|---|---|---|---|---|
| `wall` стена | дома, стены, ограды-стены, ремонт, гаражи, бордюр с прыжка | `hit-wall-light` / `-mid` / `-heavy` | 100 % | 100 % |
| `car` машина | машины потока, стоящие, коневоз; чужая с чужой | `hit-car-…` | 110 % | 100 % |
| `pole` столб | фонари, знаки, стелы, колонны, тумбы, щиты | `hit-pole-…` | 85 % | 80 % |
| `fence` забор | заборы, оградки, перила моста, лавки, столики, остановка | `hit-fence-…` | 45 % | 40 % |
| `person` человек | прохожий, клиент, мафия; лось — тоже «мягкое тело» | `hit-person-…` | 30 % | 50 % |
| `bin` бак | мусорки, контейнеры, баки, бытовки и техника строек, ракушки, конусы, котёл ведьмы | `hit-bin-…` | 60 % | 60 % |
| `tree` дерево | деревья, ельник, ёлки, кусты | `hit-tree-…` | 60 % | 80 % |

Сбиваемая мелочь (лавка, знак, куст, урна) почти не держит машину — удар о неё слабее скорости: забор —
половина скорости, высокий забор — три четверти, столб и знак — три четверти, куст — треть, урна и конус —
четверть—треть. На 60 км/ч (17 м/с) в куст — тычок, в фонарь — средний. Свой звук «снёс» (`smash`, `pole`,
`glass`) звучит как раньше — поверх.

### Слои — имена файлов

По 3—4 варианта (`hit-wall-mid-1.mp3`, `-2` …); один и тот же вариант **подряд не повторяется** (так у всех
звуков игры). Длина: тело 0,5—1,2 с, без тишины в начале.

| имя | что звучит | когда |
|---|---|---|
| `hit-<материал>-light` | тело: лёгкий стук по материалу | тычок |
| `hit-<материал>-mid` | тело: удар покрепче | средний |
| `hit-<материал>-heavy` | тело: авария | авария |
| `hit-metal-mid` | короткий хруст жести своего кузова | средний |
| `hit-metal-heavy` | долгий хруст и скрежет кузова | авария |
| `hit-boom` | низкий глухой удар «в грудь», без металла | только авария |
| `hit-glass` | стекло своей машины разбилось: звон и осколки | удар разбил стекло (≥ 15 м/с или по треснувшему) |
| `hit-glass-crack` | стекло треснуло: сухой щелчок | удар ≥ 9 м/с у стекла |
| `hit-lamp` | фара или задний фонарь разбился: хлопок пластика | удар в угол ≥ 8 м/с |
| `hit-debris` | деталь стучит об асфальт (громче — бампер и крышка, тише — колпак и зеркало) | каждый отскок отлетевшей детали |
| `scrape-wall` | **петля**: скрежет бортом о стену | пока трёшься о стену, дом, забор быстрее 3 м/с вдоль (громче к 18 м/с) |
| `scrape-car` | **петля**: скрежет металла о металл | пока трёшься о машину; нет файла — `scrape-wall` |

Материалы: `wall`, `car`, `pole`, `fence`, `person`, `bin`, `tree` — 21 имя тела. Стекло, обломки и петли —
только у своей машины; тело, хруст и «бум» — у любого удара (и у чужих машин между собой — в мире, тише вдали).

### Чтобы не было каши

- **Не больше 6 слоёв сразу** (`IMP.VOICES`). Новый слой важнее звучащего (тело важнее хруста и стекла,
  те — важнее обломков) — звучащий тихо гаснет за ~0,05 с; не важнее — новый не звучит.
- **Один удар — один звук:** нос и корма, место удара и потеря сердца — повтор ближе 5 м за 0,25 с
  (`IMP.GAP`) не звучит, если он не сильнее прежнего (тычок → авария — звучит).
- Петля скрежета — одна; держится 0,12 с после последнего касания (касание мигает по кадрам), потом гаснет
  и через ~0,7 с тишины отцепляется.

**Без файлов** — синтез, у каждого материала свой: стена — низкий глухой удар и крошка; машина — «бонг»
жести и хлопок; столб — звонкий «донг» с долгим хвостом; забор — стук и дребезг досок; человек — мягкий
шлепок без звона; бак — гулкое пустое железо и кувыркание; дерево — деревянный стук и шорох листвы. Хруст
кузова — дробь щелчков и визг жести; стекло — звон осколков и дробь падающих. У каждого — 3 варианта
(высота, число щелчков) плюс случайность ±3—5 %.

**Числа** — в `impact.js`, `IMP`: `TIER` (2,5 / 8 / 15 м/с), `VOICES` 6, `GAP` 0,25 с и `GAP_R` 5 м,
`RUB_MIN` / `RUB_FULL` (3 / 18 м/с вдоль борта); множители хруста и «бума» по материалу — `MAT`; сбиваемая
мелочь — `SMASH_MAT`.

**Проверка** (probe, без звука): `d.Snd.set(true)`, потом `d.Snd.impact(20, 'pole')` →
`{ v, mat, tier, layers: ['hit-pole-heavy', 'hit-metal-heavy', 'hit-boom'] }`. `d.Snd.hit.DEBUG`: `ST`
(удары по силе и материалу, слои, `stolen` / `dropped` — ограничитель, `gated` — повторы), `last` —
последний удар, `voices()` — сколько слоёв звучит, `rub()` — петля скрежета, `await render('wall', 20)` —
громкость синтеза слоя (rms, пик, длина) без звука; слои: материалы, `metal`, `boom`, `glass`, `crack`, `lamp`, `debris`.

## Мотор из записей (М3)

С 09.10.2026 гул мотора — как в гонках: **4 петли на ровных оборотах** (холостые, низкие, средние, высокие),
и игра плавно смешивает две соседние по оборотам, подстраивая их высоту. Код — `src/game/motor.js`.
Ползунок «мотор» (визг шин и гул потока — «звуки»), `?mute` глушит всё.

**Как играет.** Обороты считаются из скорости и передачи. Коробка своя: у «жигулей» и иномарок 5 передач,
у УАЗов 4; вверх — у красной зоны на газу (92 % оборотов, без газа — 72 %), вниз — когда обороты упали ниже
36 %. На переключении вверх газ на 0,16 с проваливается (громкость 40 %), обороты падают, щёлкает `gear`.
Петли: обороты между «низкими» и «средними» — звучат обе, по закону «равной мощности» (cos / sin), посередине
громкость не проседает; каждая петля играет быстрее или медленнее (обороты / обороты записи, от 0,5 до 2).
Газ — громче и ярче; сброс — тише и глуше (фильтр); холостые без газа — 30 % громкости (ровный гул на
стоянке не надоедает).

| что | как звучит | когда |
|---|---|---|
| **рывок с места** | обороты сразу на ~40 %, короткий «вжик» шин | газ с места |
| **газовка** | обороты к красной и отсечка | упёрся газом в стену / машину дольше 0,35 с; колёса в воздухе на газу |
| **отсечка** | «тр-р-р»: гул пропадает на 30 мс каждые 65—85 мс, обороты подпрыгивают; файл `rev-limit` — поверх | обороты у красной на газу (нитро в 5-й, газовка) |
| **хлопки на сбросе** | 1—2 (больной мотор — до 3) «пах» с огоньком и клубом из трубы (exhaust.js, `backfire`) | отпустил газ с высоких оборотов (с 62 %, быстрее 8 м/с): «жигули» — в половине случаев, УАЗ — в трети, иномарки — редко (12 %); больной мотор — вдвое чаще |
| **перегазовка** | обороты подскакивают | понижение передачи на тормозе |
| **визг шин** (`tire-squeal`, «звуки») | петля, громче — сильнее | занос (снос вбок с 3,5 м/с, в полную силу — 10 м/с), ручник быстрее 5 м/с, тормоз быстрее 13 м/с (первые 1,2 с громко, дальше тише), рывок с места; мокро — тише вдвое, снег — почти нет, песок и вброд — нет |
| **стартер** (`starter`) | «вжжж-вжжж» ~0,6 с, потом мотор схватывает: обороты подлетают и садятся на холостые | старт смены (и «просто покататься») |
| **заглохла** | гул садится вместе с оборотами за ~1 с (поверх — `engine-stall` из cars.js); завёлась — снова подхват | поломка, авария, утонул |
| **«чихи» перед поломкой** | на каждый чих дыма (exhaust.js) гул на 0,12—0,22 с пропадает | последние 3,5 с перед «заглохла» |
| **свист нитро** (`nitro-whistle`) | свист турбины растёт за 1,4 с, плюс шипение; обороты +6 % | пока жжёшь нитро (и бист-мод с нитро) |
| **больной мотор** | троит: ровный провал раз в цикл (один цилиндр не работает), случайные «чихи», обороты гуляют на холостых | ресурс мотора (cars.js, «мотор %») ниже 70 %; к 15 % — сильно |
| **Буханка** | поверх гула — вой раздатки, выше с каждой скоростью | УАЗы на ходу |
| **машины потока** («звуки», в мире) | тихий гул двух ближних едущих машин: слева / справа, тише вдали, выше — быстрее едут | ближе 34 м |

### Файлы

12 петель — `engine-vaz-idle.ogg`, `engine-vaz-low.ogg`, `engine-vaz-mid.ogg`, `engine-vaz-high.ogg`, то же для
`uaz` и `foreign`. Плюс `tire-squeal`, `nitro-whistle` (петли), `starter`, `rev-limit`.

- **Петля** — бесшовная (конец переходит в начало без щелчка), 2—5 с, моно, **обороты ровные** всю петлю —
  те, что в таблице (обороты записи); другие — скажите, поправим числа `rpm` у класса.
- Громкость петель игра выравнивает сама (к одной громкости, как у синтеза) — нормализовать не обязательно.
- **Класс берёт файлы, только когда лежат все 4 петли** — иначе синтез (смесь файла и синтеза звучала бы
  разными машинами). Нет своих у УАЗа или иномарки, но есть все 4 «жигулей» — звучат петли «жигулей» (на
  своих оборотах). Положил файлы во время игры — мотор переходит на них в течение ~0,5 с.

**Записать «Семёрку» на телефон:** машина на нейтрали, телефон у выхлопной трубы (сзади справа, ~1 м, без
ветра), по тахометру держать ровно 900 (холостые), 2500, 4000 и 5600 об/мин по 10—15 с каждые. Потом в
редакторе (Audacity) из каждой — вырезать 2—4 с самого ровного места и сделать бесшовной (Эффекты →
«Сшивание» или вручную: начало и конец — в ноль). Назвать `engine-vaz-idle` … `-high`, положить в `public/sfx`.
Или сгенерировать: `npm run sfx -- --only=engine-vaz-idle,engine-vaz-low,engine-vaz-mid,engine-vaz-high`
(промпты в `tools/sfx-list.json`; нейросеть держит обороты хуже настоящей записи).

**Без файлов** — синтез по той же схеме: при первом звуке (в меню заранее, по одной петле раз в 0,3 с) игра
сама «записывает» 4 петли класса по ~1 с: вспышки в 4 цилиндрах на оборотах записи (у «жигулей» и УАЗа —
неровные: у каждого цилиндра своя сила и разброс), резонансы выхлопа, низ и «грязь» — дальше смешивает их
так же, как файлы. Это не один пищащий тон, а гул с гармониками.

**Числа** (в `motor.js`): `ENG` — громкость `VOL` 0,075 и доли `IDLE` / `OFF`, переключение `SHIFT` / `UP` / `DOWN`,
рывок `LAUNCH`, газовка `PUSH`, отсечка `CHOP`, хлопки `LIFT`, больной мотор `SICK`, визг шин `SQ`, нитро `NOS`,
поток `TRAF`; `CLS` — у класса обороты петель, холостые, красная, передачи (`gears` — доля максималки у
красной), шанс хлопка `lift`, звучание синтеза `syn`.

**Кадр:** 4 петли + фильтр + пара узлов; параметры — раз в кадр и только когда поменялись: ~0,1 мс на кадр
(`perf()`). Синтез одной петли — ~3—4 мс один раз (в меню; на «Деке» ~10 мс).

**Проверка** (probe, без звука): `d.Snd.set(true)`, потом `d.Snd.motor.DEBUG.state()` — класс, файлы или синтез,
передача, обороты, громкость, доли петель (`layers`) и их скорость (`rate`), ресурс, визг, нитро, голоса потока;
`.ST` — переключения, отсечки, хлопки, «чихи», рывки стартера; `.sick(10)` — мотор как с ресурсом 10 % (`null` —
как в игре); `.render('uaz', 0)` — rms / пик петли синтеза; `await .sweep('vaz')` — громкость смеси от холостых
до красной (без провалов на стыках петель); `.perf()` — мс на кадр.

## Город шумит (М7, фон)

С 09.10.2026 под ездой всегда тихо шумит город: петли (длинные звуки по кругу) и редкие звуки по месту,
времени суток и погоде. Код — `src/game/ambience.js`. Громкость — ползунок «звуки», `?mute` глушит.

**Как играет.** Каждые 0,1 с игра решает, что сейчас слышно и насколько (0—100 %), и звучат **не больше
четырёх петель** — самые слышные; лишняя тихо гаснет. Переходы плавные: громкость доходит до новой за
~1,5 с (новая петля вступает, когда освободилось место). Пауза, диалог, гараж, карта — фон гаснет за ~1 с,
вернулся — снова нарастает. Конец смены — тишина. В главном меню — вдвое тише и без звуков «в мире».
Играет музыка ([MUSIC.md](MUSIC.md)) — фон ещё тише: при ползунке «музыка» 100 % — на 30 %, при 50 % — на ~8 %, музыка выключена (0 %) — как без неё.

### Петли

Файл — один на имя (можно `-1`, `-2`: при каждом запуске петли — случайный), **бесшовный**: конец
переходит в начало без щелчка. 10—20 с, моно, пик около −6 дБ — фон должен быть тише ударов и мотора.

| имя | что это | когда и где | громкость |
|---|---|---|---|
| `amb-city` | гул города: далёкие машины | всегда; у проспекта и машин потока громче | 35 % на тихой улице → 100 % у потока и широкой дороги (3+ машины в 90 м); ночью вдвое тише, в дождь на треть |
| `amb-birds` | птицы | днём; у парка, леса, кладбища, деревьев дворов больше | 25 % без зелени → 100 % в парке; утром (5:15—7:40 по часам игры) в полтора раза громче — хор; вечером стихают; в дождь нет; зимой 20 %; у потока машин тише |
| `amb-crickets` | сверчки | ночью (по часам игры с ~23:00, в полную силу с полуночи, до ~5:00), у зелени громче | лето 100 %, осень 50 %, весна 40 %, зима и снег — нет; в дождь нет |
| `amb-wind` | лёгкий ветер | всегда фоном | ~18 %; в дождь +20, зимой +20, в грозу +25; в ураган его заменяет вой |
| `amb-storm-wind` | вой урагана (раньше синтез без имени) | ураган | от силы ветра; высота синтеза — от порывов |
| `amb-rain-roof` | дождь по крыше машины | дождь (снег не стучит) | 70 % в дождь, 100 % в грозу и ураган (синтез — ниже и гуще) |
| `amb-crowd` | гул толпы | у фестиваля на парковке ТЦ (слышно до 170 м), марша протеста (150 м), драки и концерта во дворе (120 м) — **в мире**: тише вдали, слева / справа | у ближней толпы; марш — 100 %, драка — 80 %, концерт — 70 % |
| `amb-construction` | стройка: молоток, болгарка | у участков строек (`construction.js`), **в мире**, слышно до 120 м | только с 7:00 до 19:00 по часам игры, в дождь тише |

синтеза (rms, пик) без звука.


## Генерация (ElevenLabs, М2а)

Звуки не надо искать по стокам: их делает нейросеть **ElevenLabs** (Sound Effects) по описанию словами.
Описания уже написаны — для каждого имени из таблицы выше: что звучит, длина, сколько вариантов
(частым звукам — удар, монетка, клаксон — по 3—4, редким — 1—2). Список — `tools/sfx-list.json`
(по-английски для нейросети, рядом по-русски — что это в игре). Все звуки в стиле «ретро-аркада,
лоу-фай, без музыки».

**Сколько:** 159 звуков, 339 файлов, около 7½ минут звука вместе (с петлями «город шумит», мотора и ударами слоями).
Цена — меньше доллара по прайсу API (≈ $0,91) или ≈ 18 200 кредитов подписки (тарифа Starter, 30 000 кредитов в месяц,
хватает на всё с запасом на перегенерацию). Точную цифру перед запуском показывает `--dry`.

### Первый раз

1. **Аккаунт.** Зарегистрироваться на elevenlabs.io и взять **платный план (Starter, $6 в месяц, или
   выше)**: на бесплатном звуки нельзя продавать в игре, на платном — коммерческое право есть.
   После генерации подписку можно отменить — сделанные звуки остаются ваши.
2. **Ключ.** На сайте: профиль (слева внизу) → **API Keys** → **Create API Key**, право — Sound Effects.
   Ключ показывается один раз — скопировать.
3. **Положить ключ.** В корне проекта (рядом с `package.json`) создать файл **`.env.local`** с одной
   строкой: `ELEVENLABS_API_KEY=ваш_ключ`. Этот файл в git не попадает (он в `.gitignore`), никому не
   уходит.
4. **Посмотреть, что будет:** `npm run sfx -- --dry` — список звуков, сколько файлов и примерная цена.
   Ничего не отправляет и денег не тратит.
5. **Сгенерировать:** `npm run sfx`. Файлы ложатся в `public/sfx` как `coin-1.mp3`, `coin-2.mp3`…;
   в конце — таблица «из файлов / синтез». Занимает несколько минут. Оборвалось или кончились
   кредиты — просто запустить ещё раз: звуки, у которых файлы уже есть, пропускаются.
6. **Послушать:** F5 в игре — звуки уже из файлов. Удобнее — пульт в песочнице интерфейса:
   `npm run ui` → экран **«Звуки → все звуки»**: кнопка на каждое имя (случайный вариант) и цифры —
   каждый вариант отдельно; серое — файла нет, звучит синтез.

### Лишний вариант, плохой звук

- **Выкинуть вариант:** удалить файл из `public/sfx` (например, `honk-3.mp3`) и F5. Остальные
  варианты играют как раньше; номера могут идти с дыркой — не страшно.
- **Перегенерировать один звук целиком:** `npm run sfx -- --only=honk --force`. Старые файлы этого
  звука не удаляются, а уезжают в папку `.sfx-old` (вернуть — перетащить обратно в `public/sfx`).
  Можно несколько имён через запятую: `--only=honk,coin --force`.
- **Звук не тот по смыслу** — поменять его описание в `tools/sfx-list.json` (или сказать агенту, что
  не так: «удар звучит как пластик, нужен металл») и перегенерировать, как выше.
- **Громче / тише остальных** — сказать: поправим одно число на это имя (`GAIN` в `sfx.js`).
- **Не больше N звуков за раз** (попробовать на нескольких): `npm run sfx -- --limit=5`.

Петли «город шумит» (`amb-…`) генерируются вместе со всеми — бесшовными (флаг петли у ElevenLabs).
Петли мотора (`engine-…`, М3), визг шин и свист нитро — тоже петли и тоже генерируются вместе со всеми (стиль у
них свой — «реалистичная запись», не «ретро-аркада»). `--loops` нужен только для петли, которую игра ещё не берёт.

## Как проверить

- `npm run sfx:index` — какие имена из файлов, какие синтезом, неизвестные файлы.
- Песочница интерфейса (`npm run ui`) → «Звуки → все звуки» — послушать каждый файл.
- `npm run sfx -- --dry` — сверка списка генерации с игрой: имя, которое игра знает, а в
  `tools/sfx-list.json` его нет (или наоборот), — предупреждение «⚠».
- В игре с `?debug`: `__dlv.Snd.SFX.STATS` — `listed` (файлов в списке), `loaded` (раскодировано),
  `file` / `synth` — сколько раз сыграл файл / синтез по именам, `errors` — сломанные файлы.
- probe (без звука, `?mute`): `npm run probe -- --js="d.Snd.set(true); await wait(1500); d.Snd.coin(); return d.Snd.SFX.STATS"` —
  `file.coin: 1`, если лежит `coin.*`, иначе `synth.coin: 1`.
