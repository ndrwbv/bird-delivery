# Публикация в Яндекс Играх — что сделать руками

Источники: <https://yandex.ru/dev/games/doc/ru/> (SDK, консоль) и
<https://yandex.ru/dev/games/doc/ru/concepts/requirements> (требования). Сверено 26.09.2026.
Пометка **[не проверено]** — не нашёл в документации, уточнить в консоли.

## 1. Аккаунт и выплаты

1. Войти Яндекс ID в консоль разработчика <https://games.yandex.ru/console/> и принять оферту.
2. Для денег с рекламы — заполнить платёжные данные в консоли. Можно самозанятым,
   ИП или юрлицом **[точный список статусов и документов — в форме консоли]**.
   Доля разработчика — 50 % выручки с рекламы, выплата от 3000 ₽.
3. Без реквизитов игру можно выпустить, но денег не будет.

## 2. Сборка

```sh
npm run build:yandex        # → release/yandex-<version>.zip (версия из package.json)
```

Скрипт печатает вес архива и ругается, если он больше 100 МБ, если в `index.html`
нет `<script src="/sdk.js">` или в сборке есть внешние адреса. В корне архива
`index.html`, имена файлов латиницей без пробелов. У нас ~0.4 МБ.

## 3. Проверка до загрузки

- Без Яндекса: `npm run dev:yandex` (порт 5191). Вместо SDK заглушка
  `src/platform/yandex-mock.js`: реклама, таблица, облако, вход. Параметры
  `?lang=de`, `?mock-auth`, `?mock-noads`, `?mock-old-lb`, `?mock-fail`.
- С настоящим SDK на своей машине:
  ```sh
  npm run build:yandex
  npx @yandex-games/sdk-dev-proxy -p dist/yandex --dev-mode=true
  ```
  Прокси отдаёт `/sdk.js`, тестовую рекламу и данные. Открыть адрес, который он напечатает.
- Черновик в консоли: после загрузки архива есть ссылка на черновик. Там SDK
  боевой, только игру видишь ты один. Проверить на телефоне и на компьютере.

## 4. Черновик в консоли

1. «Добавить приложение» → загрузить `release/yandex-<version>.zip`.
2. **Название**: до 50 символов, на каждом языке игры (как минимум ru и en).
3. **Описание** («Об игре») и **«Как играть»**: по 100–1000 символов на каждом языке.
4. **Картинки** (на каждый язык можно свои):
   | что | размер | формат |
   |---|---|---|
   | иконка | 512×512 | PNG |
   | обложка | 800×470 | PNG/JPG |
   | витрина (промо) | 1560×520 | PNG/JPG |
   | скриншоты | ≥ 2 на каждую платформу (десктоп и мобильные), длинная сторона 1280–2560 | PNG/JPG |
   | видео | 16:9, MP4, до 28 с — **обязательно** | MP4 |
   На картинках нет чужих брендов, людей и текста на другом языке, чем у карточки.
5. **Платформы**: компьютер + мобильные (игра умеет касание). Ориентация — горизонтальная
   **[проверить, что в вертикали на телефоне показываем «поверни экран»]**.
6. **Языки**: отметить все 15 (ru en tr de es pt fr it pl uk kk uz be ja zh), если
   словари готовы. Язык игра берёт из SDK сама.
7. **Возрастной рейтинг**: **12+**. На Яндексе игра идёт в мягком режиме: без крови,
   сбитые падают со звёздочками. 16+ — если есть реалистичная кровь, 18+ — расчленёнка;
   высокий рейтинг режет аудиторию и витрину.
8. **Категория**: «Гонки» + «Аркады» **[точные названия из списка консоли]**.
9. **Таблица лидеров**: раздел «Лидерборды» → создать:
   - техническое имя **`shift`** (ровно так, его ищет код `LB_NAME`);
   - тип «числовой», сортировка по убыванию (больше — лучше);
   - название «Лучшая смена» / «Best shift» на всех языках.
   Пока её нет, игра молча показывает локальную таблицу.
10. **Реклама**: включить полноэкранную и видео за награду в разделе монетизации.
    Частоту полноэкранной задаёт площадка, в коде ничего менять не надо. Стартовую
    рекламу площадка показывает сама.
11. Отправить на модерацию. Проверка идёт 3–5 рабочих дней. После каждого отказа
    пауза до следующей отправки удваивается, поэтому сначала пройти чек-лист
    `docs/YANDEX-AUDIT.md`.

## 5. Частые причины отказа (что проверить самому)

- `LoadingAPI.ready()` не позвали или позвали позже 90 с; не размечен
  `GameplayAPI.start/stop`.
- Звук играет в свёрнутой вкладке или во время рекламы (он должен стихнуть за 2 с).
- Реклама не на паузе в игре, в середине заезда или через 2 с после нажатия, а не сразу;
  видео за награду без подписи «реклама» или без реальной награды.
- Выделение текста, контекстное меню, скролл страницы на телефоне.
- Ссылки наружу, запросы на чужие домены, шрифты и картинки с CDN.
- Язык интерфейса не совпадает с языком Яндекса; непереведённые строки;
  название и скриншоты на другом языке.
- Прогресс не сохраняется (облако для вошедших, локально для гостей); вход без
  нажатия кнопки; гость не может играть.
- Контент: алкоголь, табак, наркотики, чужие бренды, реальные люди, грубость и
  шутки про терроризм, кровь выше заявленного рейтинга.
- Картинки карточки не того размера, нет видео, описание короче 100 символов.
