# Залить в Яндекс Игры — что сделать руками

Сверено с докой 26.09.2026: <https://yandex.ru/dev/games/doc/ru/>. Сверка игры с требованиями — [YANDEX-AUDIT.md](YANDEX-AUDIT.md).

## Один раз

1. Войти своим Яндекс ID в <https://games.yandex.ru/console/> → заполнить профиль разработчика
   (имя латиницей).
2. **Подписать договор** (второй этап профиля: ИНН, банк, адрес; можно самозанятым, ИП, юрлицом,
   физлицом). Без него нельзя отправить на модерацию. Реклама включается сама после договора.
   Доля — 50 % выручки, выплата раз в месяц от 3000 ₽.

## Каждый релиз

1. `npm run build:yandex` → `release/yandex-<версия>.zip` (версия — в `package.json`; в CI-релизе это номер релиза, он же — в углу заставки).
2. Проверить локально с настоящим SDK:
   `npx @yandex-games/sdk-dev-proxy -p dist/yandex --dev-mode=true` → https://localhost:8080.
3. Консоль → «Добавить игру» (или своя игра → «Черновик») → «Общее → Архив» → загрузить zip.
4. Открыть черновик с панелью отладки: все индикаторы зелёные (SDK, Game Ready, язык, геймплей).

## Карточка (первый раз)

| поле | что |
|---|---|
| название | до 50 знаков, на каждом языке: «Птица Пицца», «Birdy Pizza»… (как в словарях `src/i18n/*.json`) |
| об игре / как играть | по 100–1000 знаков на каждом языке |
| иконка | 512×512 PNG (сейчас заглушка `public/icon.png` — лучше нарисовать) |
| обложка | 800×470 PNG, не скриншот |
| витрина | 1560×520 |
| скриншоты | ≥ 2 на десктоп и ≥ 2 на телефон, длинная сторона 1280–2560, 70 % — геймплей, без крови |
| видео | 16:9 MP4 до 28 с — **обязательно** |
| платформы | компьютер, телефон, планшет; ориентация — любая |
| языки | все 15: ru en tr de es pt fr it pl uk kk uz be ja zh |
| возраст | **12+** (на Яндексе игра без крови) |
| категории | до двух: гонки, аркады |
| облачные сохранения | поставить галочку |

**Лидерборд:** вкладка «Лидерборды» → создать: техническое имя **`shift`** (ровно так), числовой,
по убыванию, основной, название «Лучшая смена» / «Best shift».

Отправить на модерацию: 3–5 рабочих дней. После отказа пауза до новой отправки каждый раз
удваивается — поэтому сначала пункт 4 выше.
