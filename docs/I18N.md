# Переводы

Ключ — русская строка, словарь языка — `src/i18n/<lang>.json`: `{ "русский": "перевод" }`.
Список всего, что надо перевести, с местом в коде — `src/i18n/_source.json`
(`npm run i18n:extract`, флаг `--missing` покажет, чего не хватает в каждом словаре).
Нет перевода — берётся английский, нет и его — русский.

Языки: ru (исходник), en, tr, de, es, pt, fr, it, pl, uk, kk, uz, be, ja, zh.

## Правила для словарей

- `{имя}` — подстановка, переносится как есть, менять можно только её место во фразе.
- Ключи с `"plural": true` в `_source.json` — множественное: значение не строка, а объект по
  категориям `Intl.PluralRules` языка, например en `{ "one": "{n} order", "other": "{n} orders" }`,
  pl `{ "one", "few", "many", "other" }`, ja/zh — только `other`. Русский исходник: `одна|несколько|много`.
- HTML-теги внутри строки (`<b>`, `<span class="sub">`) сохраняются.
- Кнопки и хад — коротко, как в исходнике: экран телефона узкий, шрифт пиксельный.
- Тон — лёгкий, разговорный, с юмором; не дословно, а как сказал бы носитель. Никакого мата,
  алкоголя, табака и наркотиков — площадки (Яндекс Игры) такое не пропускают.
- Имена улиц не переводятся — игра сама транслитерирует их для языков без кириллицы.
- Узбекский — латиница (Oʻzbekcha).

## Пародийные вывески (src/game/brands.js)

Вывески магазинов — пародии на известные сети (Четвёрочка, Бизон, Дикая ягода…) и
выдуманные названия. В других языках — тоже пародия или нейтральное название по смыслу,
но не настоящий бренд и не его прямой перевод, если он совпадает с реальной сетью в
стране языка (например, «Дикая ягода» в английском — не «Wildberries», а «Feral Berry»).
