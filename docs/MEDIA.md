# Скриншоты, видео и обложка — автоматически

Всё медиа для карточки снимается скриптом: игра открывается в Электроне вне экрана
(1920×1080 или телефон 1080×1920), сцены ставятся через отладочную ручку `window.__dlv`,
кадры пишутся в PNG, видео — прямо в ffmpeg.

## Одной командой

```bash
npm run media
```

Собирает яндексовую версию (детская, без крови), снимает на ru, en и es и кладёт в
`media/<язык>/` (папка в гит не едет):

| файл | куда в консоли |
|---|---|
| `shot-1-order.png` … `shot-7-map.png` (1920×1080) | Скриншоты → Десктопные (альбомная) |
| `m-*.png` (1080×1920) | Скриншоты → Мобильные (портретная) |
| `video.mp4` (1920×1080, 30 к/с, 27 с, без звука) | Видео геймплея → Горизонтальное |
| `cover-800x470.png` | Иконка и обложка → Обложка |
| `icon-512.png` | Иконка и обложка → Иконка |
| `showcase-1560x520.png` | витрина (если попросят) |

Нужны: ffmpeg (`brew install ffmpeg`) и Pillow (`pip3 install pillow`).

## По шагам и для одного языка

```bash
npm run build:yandex
npx electron tools/capture.cjs --lang=de            # скриншоты 1920×1080
npx electron tools/capture.cjs --lang=de --mobile   # скриншоты телефона
npx electron tools/capture.cjs --lang=de --video    # видео
node tools/media-post.mjs                           # обрезка видео, обложка, иконка
```

`--dist=web` — снять взрослую версию (для Стима: кровь, пиво, курилка).

## Что в кадрах и как поменять

Сцены описаны в `tools/capture.cjs`:

1. заставка;
2. анкета заказа;
3. езда по маршруту (простой автопилот держит правую полосу и тормозит перед машинами);
4. вручение — гость ставится на тротуар впереди, машина подкатывает и тормозит;
5. нитро;
6. ночь (`ENV.t = 0.84`);
7. дождь (`ENV.rain = 1`);
8. карта района.

Видео — те же сцены подряд. Новая сцена — ещё один блок `await js(…)` + `await shot('имя')`.
Перед съёмкой скрипт чистит сохранения: без гайда, без учебного заказа (в нём город
пустой и тихий) и с опытом 4 (заказы посложнее).

## Правила Яндекса для медиа

- скриншоты — минимум 2 на платформу, длинная сторона 1280–2560, на 70 % — сам геймплей;
- видео — горизонтальное 16:9 обязательно, до 28 с;
- обложка и иконка — не голый скриншот (поэтому поверх кадра — логотип и название);
- без крови и шокирующего в промо — поэтому снимаем детскую версию.
