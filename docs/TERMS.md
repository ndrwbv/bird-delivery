# Словарь терминов

Слова, которые автор и агенты понимают одинаково. Для переводов игры — отдельный глоссарий в
[I18N.md](I18N.md#глоссарий).

| слово | что значит |
|---|---|
| **сессия** | Игрок сел играть после перерыва: первый запуск за календарный день или после **4 часов** без игры (`DIRECTOR.GAP_H` в econ.js; время последней игры — ключ `dlv-last-play`, пишется раз в минуту, пока игра открыта). Перезапуск раньше — та же сессия, со всеми её доставками. Внутри одной сессии может быть несколько смен. Начало сессии — спокойное: первые 2 заказа без событий, дальше по нарастающей ([CAREER.md](CAREER.md#режиссёр-событий) → «Режиссёр событий»). |
| **смена** | Один рабочий выход курьера в карьере: от «на смену» до итогов ([CAREER.md](CAREER.md)). |
| **заказ** | Одна выдача из пиццерии: один или несколько адресов ([ORDERS.md](ORDERS.md)). |
| **событие** | Что-то, что случается в городе само и отвлекает от доставки: налёт, марш протеста, банда у пина, гопники, приглашение домой, фестиваль, драка компаний, лось, ураган и т. п. |
| **катсцена** | Постановочная сцена с камерой: игрок не управляет, мир стоит, в кадре только актёры — вступление, главы историй героев (`story.js`). Не путать с диалогом поверх езды. |
| **хад** | Всё, что поверх езды: сердца, деньги (копилка и «за смену»), часы заказа, радар, кнопка паузы. Окна, меню и накладная — не хад. |
| **заход работы** | Для агентов: один подход к плану (несколько задач подряд до коммита и релиза). После захода — обновить план целиком (CLAUDE.md). |
| **ЕНО** | «Единое независимое общество» — так жители Солнечного зовут свой закрытый город и его порядок: «однажды решили создать ЕНО, вот так все тут и оказались» (автор 20.10, [LORE.md](LORE.md)). |
| **пихло** | Широкая лопата-движок для снега (слово автора, 20.10: «батя пошёл пихлом снег во дворе расчищать»). |
| **управляющая** | Женщина, которая ведёт одну пиццерию: пишет в чат, подводит итоги смены, встречает при переводе. В каждой из пиццерий — своя, разного типажа; над всеми — владелец Евгений (идея автора 20.10, [LORE.md](LORE.md) «Сеть»). Сейчас в игре вместо них один Толик на все пиццерии; Толика убираем (автор 21.10), управляющие меняются при переводе. |
| **оценка** | Звёзды 1—5 и фраза клиента после доставки, приходят сообщением, когда отъехал (идея автора 20.10). Не путать с **рейтингом смены** — местом среди своих курьеров в таблице. |
| **свободная езда** | То же, что режим «покататься»: без заказов и часов смены. Не путать с «окном покататься» — паузой без событий внутри смены (`rhythm.js`). |
