# Плавные улицы (11ч) — план этапов

[← понятнее, как играть](clarity.md) · задача [11ч](clarity.md#c11ch)

**Решено (23—24.10, разбор агента):** скруглять **в игре**, модулем `src/game/roadsmooth.js` (по образцу `RINGM.roundOff`,
`WIDEN.widen`), сразу после `roundOff` и до `fixMap`. Узлы перекрёстков, концы, мосты, малые круги — не трогать; скругляем
только изломы внутри цепочек (узел с двумя улицами). Срез угла ограничен (≤ 1,5—3 м), чтобы данные выгрузки (сужения, бульвары,
КПП, остановки, переходы) остались верными. **С 24.10 включено по умолчанию** (этапы 0—5 сделаны, задача 11ч — в архиве); `?oldroads` — старые улицы углом.

<details><summary><b>Радиусы и запретные зоны</b></summary>

| класс | радиус оси | предельный срез угла |
|---|---|---|
| 1—2 | 40 м | 3 м |
| 3 | 30 м | 3 м |
| 4—5 | 20 м | 2,5 м |
| 7 (проезды) | 8 м | 1,5 м |

Скруглять при изломе 6—120°; шаг дуги ≤ 10° на вершину, хорда ≥ 1,5 м, координаты с шагом 0,01. Без дуги: у перекрёстка
`maxW/2 + 1,2 + ZW + 7` (≈ 17—21 м), у проездов 4 м; ±20 м от остановки; ±8 м от перехода, светофора, переезда, КПП, ворот.
Дома: по точкам дуги через 1 м — край полотна и тротуара не в доме, иначе радиус ×0,75 до минимума, потом не скруглять.
