## Трек 6. Вайлдвуд (американский город)

**Статус:** идея, пункт «Выбор страны» → «Когда-нибудь потом».

**Условие для старта:** англоязычные ролики про Солнечный из трека «Продвижение» не цепляют иностранцев.
Если цепляют — Вайлдвуд ждёт: экзотика закрытого советского города и есть крючок для
иностранцев, а американская доставка пиццы им не новость.
