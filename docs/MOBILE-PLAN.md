# План: игра на iOS и Android

План для агента: этапы по порядку, у каждого — что сделать, где, как проверить и когда этап
готов. Почему так, а не иначе (обёртка вместо нативного кода, нагрев, ревью Apple) —
[IOS.md](IOS.md). Записано 04.10.2026.

**Коротко:** та же игра из `src/` в обёртке **Capacitor** — одно приложение на две площадки:
`ios/` (Xcode) и `android/` (Android Studio). Взрослая версия 18+, бесплатно с рекламой Яндекса
(решение 04.10.2026, см. ниже). Когда начинать — [ROADMAP.md](ROADMAP.md) → трек «Телефоны». Сверху —
нативный слой, без которого Apple не пропустит, а телефон раскалится: настройки графики,
сохранения в системе, вибрация, Game Center / Google Play Games, заставка, жесты у краёв.

## Решения автора — до начала работы

| вопрос | по умолчанию в плане |
| --- | --- |
| Цена | **решено 04.10.2026: бесплатно + реклама Яндекса (полноэкранная и видео за награду — те же места, что в Яндекс Играх) + покупка «убрать рекламу»**. Платную русские купить не могут: Google Play и App Store не принимают оплату в России, AdMob там не работает; Яндекс платит на русский счёт. Нужен этап «Реклама и покупка» — M (SDK Яндекс Рекламы, покупка, согласия, окно Apple «разрешить отслеживание») |
| Ориентация | обе (игра умеет); если на ревью будут вопросы — только боком |
| Магазины Android: Google Play, RuStore или оба | оба: RuStore — единственное место, где русский может купить «убрать рекламу»; проверить, берёт ли 18+ |
| Звук при беззвучном режиме iPhone | молчит (как принято в играх) |

## Правила для агента

- Все правила [CLAUDE.md](../CLAUDE.md): новая система — в свой файл, в `game.js` только хуки;
  строки через `t` / `$t` (ru в коде, en в `en.json`); git не трогать; Яндекс и детскую версию не
  собирать и не проверять.
- **Стим не ломать.** После каждого этапа — `npx vite build --mode steam` и `npm run check`.
- Игра ничего не знает о телефоне: всё площадочное — в `src/platform/`. В игре — только
  проверки вида `Platform.haptic?.('crash')`.
- **Графика не меняет игру** (этап 0): трафик рядом, физика, клиенты одинаковые на любом пресете.
- Что агент не может сам — помечено **[автор]**: деньги, аккаунты, подпись, живые телефоны.

## Этап 0. Настройки графики — M (для всех площадок, нужен до телефонов)

Пункт из [IDEAS.md](IDEAS.md), подробности — [IOS.md](IOS.md) → «Настройки графики».

- Новый файл `src/game/gfx.js`: пресеты **Низкая / Средняя / Высокая**, отдельные пункты
  («Своя», если поменяли руками), хранение в `dlv-gfx` через `Platform.store`.
- Пункты: кадров в секунду (30 / 60 / как у экрана), дальность тумана (~250 / ~370 / ~490 м,
  вместе с `cull.js`), город за меню (застывший / 20 к/с / живой), чёткость (`PIXEL_SHORT`
  ~430 / 540 / ~720), окна с комнатами (`WINS.quality`), эффекты, частота обновления машин и
  людей **вдали**.
- Ограничение кадров — в `frame()` game.js: пропускать кадр, если с прошлого прошло меньше
  1/30 с (а `dt` считать от последнего нарисованного).
- Строка «графика» в настройках (`renderSettings`), рядом со звуком.
- По умолчанию: телефон (`TOUCH`, нет геймпада) — Низкая, Steam Deck — Средняя, компьютер —
  Высокая. Платформа может задать свой: `Platform.gfxDefault`.
- Записать в [CAREER.md](CAREER.md) (раздел про настройки) словами и цифрами.

**Готово, когда:** `npm run probe -- --size=phone` на Низкой показывает ~30 кадров в секунду и
заметно меньше рисуемого (`renderer.info.render.calls`), чем на Высокой; на Высокой — как
сейчас; заезд автопилотом (`smoke`) проходит на всех трёх; переключение без перезагрузки.

## Этап 1. Режимы сборки и платформа `mobile.js` — S/M

- `vite.config.js`: режимы `ios` и `android` → `dist/ios`, `dist/android`; без песочницы,
  без `pad.html`.
- `src/platform/index.js`: оба режима берут `src/platform/mobile.js`.
- `mobile.js` по контракту [src/platform/README.md](../src/platform/README.md):
  - `id: 'ios' | 'android'` (из режима сборки);
  - `features: { ads: true /* Яндекс Реклама, после покупки «убрать рекламу» — false */, leaderboard: 'remote'|'local', externalLinks: true, nameInput: true, adult: true, quit: false }`
    — **кнопки «выйти» нет** (Apple отклоняет; на Android выходят системными жестами);
  - `init()`: `hardenPage()` из `common.js` (выделение, меню долгого нажатия, пружина
    страницы), язык из системы, пауза при сворачивании (`hub.watchVisibility()` + событие
    `App` `pause`/`resume` Capacitor);
  - `gfxDefault: 'low'`;
  - без автообновления: проверка обновлений в настройках — только где есть `SHELL` (Стим).
- Хуки сверх контракта (в игре — через `?.`, у других площадок их нет):
  `Platform.haptic(kind)`, `Platform.achievement(id)`.
- `achievements.js` → `send(id)`: звать `Platform.achievement?.(id)` вместо прямого
  `Platform.steam.achievement` (в `steam.js` добавить `achievement` на верхний уровень, чтобы Стим
  работал как раньше).
- Без Capacitor (обычный браузер, `vite --mode ios`) всё работает на заглушках — как `steam.js`
  без моста. Тогда режим можно гонять в probe.

**Готово, когда:** `npx vite build --mode ios` и `--mode android` собираются; probe с
`--mode=ios --size=phone` проходит `smoke`; Стим собирается, достижения в Стим уходят как раньше.

## Этап 2. Оболочка Capacitor — S

- Зависимости: `@capacitor/core`, `@capacitor/cli`, `@capacitor/ios`, `@capacitor/android`
  (свежая стабильная версия); плагины: `preferences`, `haptics`, `app`, `status-bar`,
  `splash-screen`, `browser`; «не гасить экран» — плагин keep-awake (сообщество).
- `capacitor.config.json`: `appId: ru.ndrwbv.birdpizza` (как в Стиме), имя «Птица Пицца»,
  `webDir` — разный для площадок (две конфигурации или `--mode` → копия в `dist/mobile`),
  iOS `scrollEnabled: false`, Android — без отладки WebView в релизе.
- `npx cap add ios`, `npx cap add android` → папки `ios/` и `android/` **в репозитории**
  (`.gitignore` — их `build/`, `Pods/`, `.gradle/`).
- Скрипты в `package.json`: `build:ios` (vite + `cap sync ios`), `ios` (открыть Xcode),
  `build:android`, `android`.
- Иконки и заставка: из `build/icon.png` через `@capacitor/assets` (если иконки ещё нет —
  временная, отметить в отчёте).

**Готово, когда:** в iOS Simulator (Xcode) игра запускается, доходит до меню, смена идёт; в
эмуляторе Android — то же (если Android Studio установлен; нет — отметить, что не проверено).

## Этап 3. Нативные мелочи — M

**iOS** (Swift в `ios/App/`, свой `ViewController` вместо стандартного Capacitor):
- статус-бар спрятан, полоска «домой» прячется (`prefersHomeIndicatorAutoHidden`);
- жесты у краёв — со второго свайпа (`preferredScreenEdgesDeferringSystemGestures` — все края),
  иначе игрок в заезде вылетает на рабочий стол;
- звук: `AVAudioSession` категория `ambient` (не глушит музыку игрока, молчит в беззвучном);
  после звонка — `Snd.resume()` через событие `resume`;
- заставка (launch screen) держится до `Platform.ready()` — без чёрного экрана, пока строится
  город.

**Android** (Kotlin в `android/app/`):
- полный экран без системных панелей (immersive), вырез камеры — игра рисует под ним, хад
  уже учитывает `safe-area`;
- **кнопка / жест «назад»:** закрыть открытую панель → иначе пауза → в паузе — ничего (не
  выходить из игры одним нажатием); событие `backButton` плагина `App`;
- экран не гаснет, пока идёт смена;
- звук: отдать фокус при звонке, вернуть после.

**Готово, когда:** в симуляторе/эмуляторе нет статус-бара, «назад» на Android ставит паузу,
после сворачивания игра на паузе и без звука, после возврата — звук есть.

## Этап 4. Сохранения — S

- `mobile.js` → `store`: синхронный кеш как у `localStore()`, но писать и в `localStorage`, и в
  Capacitor Preferences; при запуске читать Preferences (это главная копия: iOS может почистить
  данные WebView). Старое сохранение из `localStorage` — подхватить один раз.
- Облако: Android — системный Auto Backup (включён по умолчанию, Preferences в него попадают —
  проверить `android:allowBackup`); iOS — iCloud key-value (`NSUbiquitousKeyValueStore`, свой
  маленький плагин) — **можно позже**, после выхода.
- Сброс прогресса (`resetProgress()`) должен чистить и Preferences.

**Готово, когда:** прогресс переживает перезапуск приложения и «очистить данные WebView»;
сброс прогресса стирает всё.

## Этап 5. Game Center и Google Play Games — M

- Достижения: те же 32, ID и тексты — таблица [STEAM.md](STEAM.md) §4.1. Взрослые — тоже (у нас
  18+). `Platform.achievement(id)` → GameKit (iOS) / Play Games Services v2 (Android).
- Таблица: «лучшая смена» — как `BEST_SHIFT` в Стиме (`steam.js`): `leaderboard.submit/top/mine`,
  копия всегда в локальную, нет сети или не вошёл — локальная.
- Плагин: готовый плагин сообщества для Game Center / Play Games, если живой и поддерживает
  обе площадки; иначе свой маленький плагин Capacitor (Swift + Kotlin, только нужные вызовы).
- Значок Game Center в меню (iOS) — Apple любит его видеть.
- ID достижений и таблиц завести в App Store Connect и Play Console — **[автор]**, по таблице.

**Готово, когда:** без входа в Game Center / Play Games игра работает как раньше (локальная
таблица, плашки достижений); с входом — на тестовом аккаунте достижение и результат смены видны
в системном окне.

## Этап 6. Вибрация — S

- Хуки в `game.js` (по одной строке): удар о стену/машину (сила — от скорости), сбитый
  прохожий, взрыв, доставка, деньги в конце смены. `Platform.haptic?.(kind)`, в `mobile.js` —
  Haptics: `impact` light/medium/heavy и `notification` success.
- Пункт «вибрация: вкл/выкл» в настройках — только где `Platform.haptic` есть.
- Не чаще раза в 80 мс (иначе в аварии телефон гудит без остановки).

## Этап 7. Проверка «это не сайт» — S

Пройти таблицу [IOS.md](IOS.md) → «По чему ревьюер узнаёт „сайт“» в симуляторе и эмуляторе:
авиарежим, чёрный экран при запуске, пружина и зум страницы, выделение текста, долгое нажатие,
ссылки (наружу — в браузер через плагин `Browser`), подсказки про клавиатуру и мышь на
телефонном экране, iPad (раскладка не расползается). Найденное — исправить или записать в отчёт.

## Этап 8. Живые телефоны — M — [автор] + агент

Агент готовит сборку и чек-лист, автор ставит на телефоны:

- iPhone старый (11/12) и новый; Android слабый (2—3 года, средний ценник) и сильный;
- 15 минут смены на Низкой: процент батареи, «тёплый / горячий», кадры не дёргаются;
- память: нет вылета после 3 смен подряд (iOS и Android убивают WebView, если город
  съел слишком много);
- звонок посреди смены, свернуть-развернуть, геймпад (Xbox, DualSense).

Ориентир: 20—30 % батареи в час — нормально. Хуже — сначала ужать «Низкую», и только если не
помогает — думать о нативном переносе ([IOS.md](IOS.md) → «Нагрев и батарея»).

## Этап 9. Магазины — M — [автор], агент готовит тексты и картинки

**App Store:**
- Apple Developer Program (99 $/год) — **[автор]**; оплата и выплаты из России — как со Стимом
  (счёт за рубежом на своё имя), сверять на сайте Apple.
- Возраст: анкета → 18+. Карточка из [STORE-LISTING.md](STORE-LISTING.md), скриншоты 6,9"
  iPhone и 13" iPad (`tools/capture.cjs` с размером Apple), на «Низкой» — как увидит игрок.
- TestFlight → внутренние тестеры → ревью. При отказе — ответ в App Store Connect, видео
  геймплея ([IOS.md](IOS.md) → «Если всё-таки отказали»).

**Google Play:**
- Аккаунт разработчика (25 $ один раз) — **[автор]**; выплаты из России — сверять (как у Apple).
- Новым личным аккаунтам Google требует закрытый тест: 12+ тестеров 14 дней подряд до выпуска
  — сверять в Play Console, позвать знакомых заранее.
- Сборка — `.aab`, подпись через Play App Signing; уровень Android (target API) — тот, что
  Google требует в этом году.
- Возраст: анкета IARC → 18+. Карточка, скриншоты телефона и планшета.

**RuStore** (если автор решит): тот же `.aab`/`.apk`, своя анкета и выплаты на российский счёт —
проверить правила для 18+.
