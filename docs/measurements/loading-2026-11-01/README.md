## Условия

- Исходники игры: `4de18035fca9394c0747e1a5ac6b9afd55a7a202`, рабочее дерево в начале анализа чистое. Следующий коммит `42a22d4` изменил документацию в другом заходе; игру в этих измерениях он не менял.
- Сборка `tools/probe-build.cjs steam`: найденная актуальная по проверке инструмента сборка `/var/folders/sn/c880pc2s1bd03pg0j9rtgjsh0000gn/T/bird-probe/steam.1793532042135`. Она включает редактор (`BIRD_EDITOR=1`); это не отдельный замер упакованного приложения Steam.
- Apple M4, 10 логических CPU, 32 GiB RAM, macOS/Darwin 25.5.0, arm64; Electron 33.4.11.
- Steam mode, окно 1280×800, высокая графика, `gfxdev=deck`, зерно 7, CPU ×3 с начала страницы. Это эмуляция, физическая Steam Deck не проверялась.
- Звук выключен флагом Electron и `?mute`. Прогоны последовательные, сохранения автора не использовались. Каждый probe заводит свою временную сессию; кеш ОС не очищался. Язык ru задаёт probe, обычное обучение пропущено.
- Сохранённые отчёты не являются тремя повторами одного сценария; медиану из них не считать. Память в `shift.json` — текущая JS-куча в одной точке без принудительного GC, не пик приложения и не сумма CPU/GPU.

## Команды выполненных прогонов

Во всех командах `audit_build` — указанная выше временная сборка. Папка автоматически очищается инструментом; для нового измерения собрать свежую контрольную сборку по инструкции в спеке, не рассчитывать на сохранность временного пути.

```sh
audit_build=/var/folders/sn/c880pc2s1bd03pg0j9rtgjsh0000gn/T/bird-probe/steam.1793532042135
npm run probe -- --mode=steam --dir="$audit_build" --early --bootcpu --cpu=3 --seed=7 --size=deck '--q=gfx=high&gfxdev=deck&mute' --eval=tools/probe-checks/lateboot.js --report=/tmp/delivery-loading-lateboot-20261101.json --max=5000 --timeout=300
npm run probe -- --mode=steam --dir="$audit_build" --early --bootcpu --cpu=3 --seed=7 --size=deck '--q=gfx=high&gfxdev=deck&mute' --eval=/tmp/delivery-loading-audit-20261101/profile-audit.js --report=/tmp/delivery-loading-audit-20261101/profiles.json --max=4500 --timeout=360
npm run probe -- --mode=steam --dir="$audit_build" --early --bootcpu --cpu=3 --seed=7 --size=deck '--q=gfx=high&gfxdev=deck&mute&slowboot' --eval=tools/probe-checks/shift-loading.js --report=/tmp/delivery-loading-audit-20261101/shift.json --max=2500 --timeout=300
npm run check -- --serial --only=land-stream,late-wait,cull-stream
```

Последняя команда: 3/3 проверки прошли — атомарная публикация земли, ожидание Worker с fallback/поздним ответом, добавление участков в отсечение. Полный набор `check` не запускался: изменена документация, игровые прогоны сделаны для анализа. Релиз игры для этого документального изменения не требуется.
