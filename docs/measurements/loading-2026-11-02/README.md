## Методика и воспроизведение

Все 18 запусков прошли с первого раза; отклонённых или повторённых попыток не было. Строгая offline-проверка после исправления gate дала18/18: errors=[], uncaught=0, crash=[], ни error/fallback/rejected флага без учёта регистра, dropped/overflow=0, W реально двигает машину, физические координаты соответствуют выбранному району. До окончания миграции legacy __boot отсутствовал, а новый __startupTrace мог существовать раньше.

Новая карьера: район0, только русский язык и отключённый звук. Сохранённые:40 смен, counts[4,5,5,6,6,7,7,0], открыто8, partySeen=true, city=false, район0 или7, кошелёк30000. Это искусственные fixtures; реальные сохранения пользователя не использовались. Качество одинаково задано query gfx=high&gfxdev=deck. Одна изолированная Chromium-сессия на cold/warm пару: cold очищает её cache/storage, warm перезапускает процесс с тем же user-data, логические значения fixture восстанавливаются заново в обоих. ОС, файловый и драйверный кэш не контролировались; ResourceTiming во всех 18 отчётах имеет 0 записей, поэтому I/O недоступно и cache hit не установлен.

Cold/warm выполнялись последовательно:3 пары newbie →3 пары saved-near →3 пары saved-far. Паузы человека не вводились. Общий click→control — scripted wall, а не время ручного решения; дополнительные noop dispatch и polling раскрыты выше. Критерий срабатывания gate оставался одинаковым на всей серии. В этой серии startup-ready и control gate не менялись. После cooperative core/reader для №17а создаётся новый generated/cache A/B на одной окончательной сборке с исправленными visibility/fresh gate; эта прежняя серия остаётся диагностической базой, а не прямой парой к изменённому читателю.

Малый Node-тест включает 16 отрицательных вариантов этих ошибок и некорректных control/overflow/ресурсных отчётов. Это изменение приёмки, без изменения поведения игры или повторного замера.

Файлы: reports/ —18 raw + pilot; fixtures/ — только синтетические значения; stages.csv — все стадии/поля с медианой и диапазоном; summary.json — точные агрегаты и значения всех повторов; build-tree.json — SHA256 всех 93 файлов immutable candidate; integrity.json/revalidation.json — проверки; runtime-tracked.patch и measured-source/ — точные измерительные правки базы. Использование raw JSON и отдельного gate не запускает игру.
