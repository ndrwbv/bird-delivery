# Обычный ранний каталог адресов — 02.11.2026

№17б: проверенный ранний каталог подключён к обычному первому запуску Steam. Поддержанный вход: взрослая версия, русский язык, новая карьера в первом районе, стандартная «Семёрка», обычный начальный сезон, Deck mid или high. Для остальных состояний остаётся прежнее построение. Каталог хранит дома, адреса, этажность, входы, связи с исходными зданиями и возможные точки доставки. Заказы, клиенты и награды в пакет не входят.

Это данные для следующего этапа загрузки по участкам. Глобальная очередь построения и барьер начала смены сохранены; новый выигрыш времени до управления здесь **не измерен и не заявлен**. Проверки выполнены на macOS с окружением Deck, а не на физическом устройстве.

## Общая проверка

Общий `npm run check` выполнен один раз, последовательно, 43 проверки, 218 с. Все проверки игры прошли: загрузка районов, навигатор, 30 с автопилота web и Deck high CPU ×3, журнал ошибок. Web: 342 м, p95 18,5 мс; эмуляция Deck: 306 м, p95 19,7 мс. Ошибок консоли и журнала — 0. Это диагностические прогоны, не физическая приёмка Deck и не измерение выигрыша запуска.

Первый общий прогон вернул **exit 1**: старая VM-заглушка проверки probe-terminal не разрешала два действительных helper-модуля. Исправлена только граница этой проверки, затем пять её сценариев прошли и отдельный `npm run check -- --serial --only=probe-terminal` вернул **exit 0**. Исходный отказ не переписан в успех. [Первый результат](evidence/main-check-result.json), [исправленная регрессия](evidence/terminal-regression-result.json) и исходные логи сохранены. Предупреждение о 256 непереведённых строках оставлено по решению автора.
