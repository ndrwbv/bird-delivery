Затем дополнительная проверка рабочего объёма перед decode/созданием независимого target отказала по `WORKING_BUDGET`: защитный потолок 512 MiB. Стек удалось сохранить из crashlog собственной тестовой сессии. Round-trip ещё не выполнен, бинарный файл не опубликован. Эта оценка учитывает несколько временных копий для приёмки; она не является измерением кучи или памяти Steam Deck.

Исходные [report.json](attempt-1/report.json), [run.log](attempt-1/run.log), [manifest.json](attempt-1/manifest.json), [crashlog.json](attempt-1/crashlog.json) сохранены без правок. Первоначальный host guard затёр исходный evalErr общей причиной отказа и не удержал trace/числители бюджета; этот недостаток диагностики исправляется перед следующей попыткой. Успехом данный запуск не считается.

Следующая разрешённая попытка: подробные bounded diagnostics и внешний acceptance-потолок 1 GiB; кодовый default 512 MiB не меняется. Проверки точности не обходятся. После результата отдельно измеряются реальный файл, максимальный неделимый шаг и память; увеличение защитного потолка само по себе не доказывает пригодность для игры.

**Решение агента 02.11.2026: переходим к №17б.** Точность, отказ до публикации и ускорение 19–22% подтверждены; отдельная память не выявила заметного ухудшения. Обычный путь пока generated. Следующий пакет должен подготовить настоящий ordinary EDL, измерить raw/упакованный размер, точные default-mid/high inputs и обеспечить локальную поставку/проверку/fallback. Лабораторный seed7 файл нельзя просто включить игроку. До выпуска рабочего пути нужны приёмка №17б и общая проверка; цель всего №17 — 5–10 с — остаётся невыполненной.
