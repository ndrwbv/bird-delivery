# Анонимная статистика

Зачем: видеть, сколько длится игра, где бросают, какие механики включаются и чем кончаются, что ломается и как
быстро игра идёт на компьютере, Деке и телефоне — не по рассказам, а числами (трек 12 «Аналитика» в
[IDEAS.md](IDEAS.md), решение от 18.10.2026 — Яндекс Облако). Сводка словами — [STATS.md](STATS.md) (`npm run stats`).

## Что уходит из игры

Только **взрослая версия** (Стим, браузер), только если настройка включена (по умолчанию — вкл).
**Детская (Яндекс Игры, `?kids`) — ничего**: модуль даже не мерит кадры, запросов нет.

| событие | когда | что внутри |
|---|---|---|
| `session_start` | запуск игры | первый ли запуск на устройстве, язык, экран, плотность пикселей, ядра и память устройства, ОС (win / mac / linux), сколько смен уже сыграно, качество графики |
| `session_end` | закрыл игру (успевает не всегда) | сколько был в игре и сколько за рулём, смен за запуск, **где закончил** (меню, гараж, посреди смены, на чеке) |
| `hide` | свернул окно / вкладку | где был |
| `perf` | раз в минуту, пока окно видно | время кадра: половина кадров быстрее (p50), 95 % быстрее (p95), самый долгий; провалов дольше 50 мс; к/с; память; качество графики; «тяжёлый кадр»; где игрок; секунд за рулём за минуту |
| `shift_start` | начало смены карьеры | номер смены, район, «весь город», быстрый заезд |
| `shift_end` | конец смены | чем кончилась (время, опоздал…), до конца ли, длина (с) и за рулём, доставок, опозданий, деньги, удары, штрафы, сердца, воскрешения, сбито людей, разбито машин, взрывов машины, район, сезон, праздник, камера, графика, настроение чека, счётчики `m` (ниже) |
| `event` | режиссёр начал событие | вид: концерт, драка компаний, гопники, приглашение клиентки, лоси, сценка у двери / жители, глава сюжета, поручение, банда, марш, мафиози, налёт, восстание, фестиваль, ураган |
| `choice` | окно разговора с двумя ответами закрылось | шапка окна (поручение, у двери, гараж…) и ответ: 1 принял, 0 отказался, −1 закрыли без ответа |
| `errand` / `errand_end` | поручение предложено / кончилось | вид поручения, принял или отказался; довёз или сорвалось |
| `mini` | мини-игра у клиента оплачена | домофон / подъезд / разговор / встреча-катсцена и исход (быстро, вовремя, не успел, сам спустился, откупился от гопников, поторопил, поддержал, шутка зашла / нет) |
| `death` | смена сорвалась | причина: машина всё (взрыв), утонул, под лёд… |
| `error` | новая запись журнала ошибок ([CRASHES.md](CRASHES.md)) | вид (ошибка, промис, кадр, часть мира упала / выключена, зависание), где, текст (до 160 знаков), файл:строка:колонка, сколько раз; не больше 25 за запуск |

Счётчики смены (`m` в `shift_end`): `ontime` / `late` — адреса вовремя и с опозданием, `ev.<вид>` — события режиссёра,
`block` — перекрытия на обратном пути, `fly` — полёты на родстере, `roof` — прыжки на крышу с трамплина.

У каждого события — номер установки (случайные 16 знаков, в сохранении `dlv-tel-id`, общий для всех профилей),
номер запуска (случайный), время, версия (`v0.17.2` / `dev-<коммит>`), сборка (web / steam) и устройство
(компьютер / Дека / телефон — как у настроек графики).

**Не уходит:** имя курьера и профиля, ники и адреса клиентов, тексты, Steam ID, почта. IP-адрес приёмник не пишет
(журнал функции выключен). Хранится не дольше **года** (база сама стирает старое).

## Как выключить

Настройки → **игра** → **«анонимная статистика: вкл / выкл»** (и из паузы). Выкл — игра больше ничего не шлёт и
стирает неотправленное. «Сбросить прогресс» настройку и номер установки не трогает. Текст для страницы в Стиме и
политики конфиденциальности — [STEAM-COMPLIANCE.md](STEAM-COMPLIANCE.md) «Анонимная статистика».

## Как шлёт (и почему не мешает игре)

- Очередь событий в памяти; раз в **60 с** — одной пачкой (POST, `text/plain` — без лишнего предварительного
  запроса). Свернул или закрыл — `sendBeacon` (уходит, даже когда страница уже закрыта).
- Нет сети — копит до 400 событий (старые выбрасывает); при закрытии кладёт неотправленное в сохранение
  (`dlv-tel-q`, до 6 пачек) и отправляет при следующем запуске. Ошибок в консоль не пишет.
- Время кадра меряет свой `requestAnimationFrame`: одно число в кольцо, без выделения памяти; всё остальное — по
  таймеру раз в минуту. Замер 18.10.2026: кадр со статистикой и без (`?notel`) одинаковый (p50 16,6—16,7 мс, p95
  18,2—18,4 мс, probe `--cpu=3`).

## Проверки не шлют

`npm run probe`, `npm run check`, perf, tour, capture открывают игру с `?debug` / `?mute` — статистика копится (её
видно в `__dlv.tel`), но **никуда не уходит**. Dev-сервер (`npm run dev`) — тоже. Послать нарочно — `?tel`
(события помечаются `test`, сводка по умолчанию их не считает). Сборка `dev-<коммит>` (не релиз) — всегда `test`.
`?notel` — выключено совсем.

```
npm run probe -- --q=tel --js="await onShift(); autopilot(); await run(60, 3); await d.tel.flush(); return d.tel.state()"
```

`__dlv.tel`: `state()` (вкл, тихо ли, в очереди, отправлено, последний ответ), `queue()`, `flush()`, `perf()`,
`sessionEnd()`, `installId`, `sessionId`.

## Где лежит

Личное облако автора в Яндекс Облаке (`yc --profile personal`, облако `cloud-ndrwbv`), каталог **`bird-pizza`**:

| что | имя | заметки |
|---|---|---|
| база | YDB serverless **`bird-stats`**, таблица **`events`** | бесплатно до 1 млн операций и 1 ГБ в месяц; строки старше года стираются сами |
| приёмник | Cloud Function **`bird-ingest`** (Node.js 22, 128 МБ, 5 с), публичная: `https://functions.yandexcloud.net/d4eu40ddb8ngvb0aqjp6` | бесплатно до 1 млн вызовов в месяц; пачка раз в минуту → ~16 тыс. часов игры в месяц бесплатно |
| сервисный аккаунт | **`bird-ingest`** — роль `ydb.editor` только на базу `bird-stats` | от его имени функция пишет в базу; ключей у него нет |

Таблица `events`: `install_id`, `session_id`, `ts` (время события), `seq` (номер события в запуске), `event`,
`version`, `build`, `device`, `data` (JSON), `test`, `received` (время приёма). Ключ — установка, запуск, время,
номер: повторная пачка не задваивается. Как развернуть заново и поменять — [tools/telemetry/README.md](../tools/telemetry/README.md).

Приёмник принимает пачку до 64 КБ и 300 событий, только с ключом протокола `bp1` (игра шлёт его в каждой пачке),
проверяет номера, имена событий и версии, данные события режет до 2 КБ; мусор — ответ 400 без записи.

## Как смотреть

```
npm run stats                 # последние 30 дней, без проверочных → печатает и пишет docs/STATS.md
npm run stats -- --days=7     # за неделю
npm run stats -- --test       # только проверочные (probe с ?tel) — убедиться, что всё доходит
npm run stats -- --print      # только напечатать
```

Сводка: игроки и запуски, часы, средняя сессия и смена, смены за запуск, чем кончаются смены, где бросают, события
режиссёра на смену, поручения (сколько берут), мини-игры (исходы), разговоры с выбором, топ ошибок (вид, где, файл:
строка, сколько запусков, версии), скорость по устройствам и качеству графики.

Доступ — вход автора в `yc --profile personal` на этой машине (токен берётся на лету, нигде не хранится); на другой
машине — ключ сервисного аккаунта-читателя в `telemetry-reader.local.json` в корне (в .gitignore; как сделать — README).
