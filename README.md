# Птица Пицца

Аркадная доставка пиццы по настоящей Москве (район вокруг Ленинской Слободы из
OpenStreetMap): заказы от «умного трекера», трафик по полосам, светофоры, пешеходы,
погода и сутки, соперники-курьеры, гараж и находки. three.js, крупный пиксель, звук
синтезируется, картинок-файлов нет — всё рисуется кодом.

Выросла из внутренней заготовки `lab/delivery` дайджеста (копия как была — в
`original/`, в сборку не идёт). Что поменяли, чтобы игру можно было выпустить, —
[docs/CONTENT.md](docs/CONTENT.md).

## Сборки

Одна игра, три бандла — отличаются только платформенным слоем (`src/platform/`).
Две версии контента: **детская** (Яндекс, всегда: без крови, алкоголя, табака) и
**взрослая 18+** (Стим по умолчанию: кровь, пиво, курилка, биты; в настройках Стима
переключается). Флаг — `ADULT` в `src/game/moscow.js`, `?kids` — детская для проверки.

| команда | что | куда |
|---|---|---|
| `npm run dev` | локально, `localStorage`, реклама-заглушка | http://localhost:5190 |
| `npm run dev:yandex` | как на Яндексе, с заглушкой SDK (`src/platform/yandex-mock.js`) | http://localhost:5191 |
| `npm run build:yandex` | архив для консоли Яндекс Игр | `release/yandex-<версия>.zip` |
| `npm run electron` | Стим-сборка в Электроне | окно |
| `npm run dist:win` / `dist:deck` / `dist:mac` | пакеты для SteamPipe | `release/` |

Сначала Яндекс Игры — [docs/YANDEX.md](docs/YANDEX.md) (что сделать руками, чтобы залить)
и [docs/YANDEX-AUDIT.md](docs/YANDEX-AUDIT.md) (сверка с требованиями). Что вписано в
карточку (тексты ru/en/es, категории, теги) — [docs/STORE-LISTING.md](docs/STORE-LISTING.md),
скриншоты и видео одной командой `npm run media` — [docs/MEDIA.md](docs/MEDIA.md). Потом Стим —
[docs/STEAM.md](docs/STEAM.md) (Steamworks, депоты, геймпад, обновления для Deck).

## Устройство

| путь | что |
|---|---|
| `src/main.js` | вход: площадка → язык → игра |
| `src/game/moscow.js` | вся игра |
| `src/game/city-data.js` | город из OpenStreetMap (не править, не перегенерировать без нужды) |
| `src/game/people.js` | генератор людей: внешность, лица, имена по языкам |
| `src/game/brands.js` | пародийные вывески вместо чужих брендов |
| `src/game/mapcheck.js` | проверка и починка карты при загрузке, `?mapcheck` — отладка |
| `src/platform/` | web / yandex / steam: реклама, сохранения, таблица, пауза |
| `src/input/` | геймпад и навигация по меню с него |
| `src/i18n/` | переводы: ключ — русская строка, [docs/I18N.md](docs/I18N.md) |
| `electron/` | оболочка для Стима и автообновление для Deck |

Отладка: `window.__dlv` — состояние игры; `?mute` — без звука, `?nolb` — не писать в
таблицу, `?lang=de` — язык, `?mapcheck` — отчёт о карте.

Данные карты — © участники OpenStreetMap, ODbL; рельеф — SRTM (NASA). Шрифт Press Start 2P —
SIL OFL (`public/fonts/OFL.txt`).
