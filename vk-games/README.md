# Птица Пицца для VK Games

Детский пилот для браузера на ПК и телефоне. В нём часть района Юг в Солнечном, пиццерия, обучение, повторяемые смены и весь гараж из 15 машин. «Семёрка» и остальные машины используют процедурные кузова. За завершённую смену с доставкой можно получить 500 игровых ₽ за просмотр ролика VK.

На ПК и телефоне общие материалы травы, асфальта и плитки, бордюры, летние деревья, накладная и радар. Сенсорный интерфейс добавляет педали и руль. В низком пресете камера видит на 250 м, в ясную погоду дымка начинается примерно на 176 м. На телефоне короткая сторона 3D-кадра до 430 пикселей, на ПК низкий пресет рисует 1280 × 720. Оба режима используют FXAA. В мобильном режиме цель — плавные 40–45 кадр/с и выше, лимит пресетов — 60. На ПК кадры идут в ритме дисплея. Направление солнца фиксировано, под машиной игрока остаётся мягкая тень.

Во всех сменах и быстрых заездах пилота разгар лета. В быстром заезде доступны летние варианты погоды. Для проверки ясного дня открой `?debug&mute&weather=clear`.

Для предпросмотра исходной поднятой земли на 46 см добавь `raisedland=1`. Параметр действует на ПК и телефоне. В мобильной эмуляции этот вариант дольше открывает смену и даёт около 36 кадр/с, поэтому на обычном входе используются уличные бордюры и прежний рельеф.

## Сборка

Нужны Node.js 20, Git, `tar` и `zip`. Из корня репозитория:

```sh
npm ci --prefix vk-games
npm run --prefix vk-games build
```

Архив появится в `release/bird-pizza-vk.zip`. Скрипт берёт исходники и ресурсы только из коммита `2cc121e93c22497839a80b7daac1b75c3aaa4bcb`, указанного в `build.mjs`. Git должен иметь этот коммит в локальной истории. Изменения пилота хранятся в этой папке и применяются во временном каталоге. Свой lock-файл фиксирует Vite, VK Bridge и остальные зависимости сборки.

Правила конфигурации пилота лежат в `map.js`, `prepare-city.mjs`, `platform.js`, `shift-reward.js` и `game.patch`. В обычный поток сборки Steam и Яндекса эта папка не подключена.

## Подключение к VK

Распаковать архив на HTTPS-хостинг и указать URL `index.html` в настройках Web-версии игры. Хостинг должен разрешать открытие страницы во фрейме ВКонтакте. VK Bridge инициализируется при запуске внутри клиента. ID берётся из контекста запуска VK. Игровой прогресс хранится в отдельном пространстве браузера для этого игрока. При запуске напрямую с хостинга доступна сама игра, реклама появляется внутри ВКонтакте при доступности VK Bridge и рекламных показов. [Документация VK](https://dev.vk.com/ru/games/getting-started)
