Анонимная статистика

Игра отправляет разработчику анонимную статистику, чтобы чинить ошибки и делать игру лучше. Что отправляется:

  • сколько длятся заходы и смены, где игрок останавливается (меню, гараж, посреди смены);
  • какие события в игре случаются и чем кончаются (мини-игры, поручения, встречи), как идёт обучение, прогресс и покупки внутри игры;
  • где в игровом городе случаются аварии и срывы — грубо, квадратами по ~100 метров игровой карты;
  • какие экраны открываются и какие настройки меняются;
  • ошибки, падения и зависания игры;
  • плавность: время кадра и загрузки, память, качество графики, тип устройства (компьютер / Steam Deck / телефон), система, модель видеокарты, размер экрана, язык игры, версия игры.

Что не отправляется

Игрок обозначен только случайным номером установки. Не отправляются: имя, почта, Steam ID, IP-адрес, ник курьера, тексты, сохранения. Разработчик не может узнать, кто вы.

Где хранится

В Яндекс Облаке (Россия), не дольше одного года, только у разработчика; никому не передаётся и не продаётся.

Как выключить

Настройки → Игра → «анонимная статистика: выкл». После этого игра не отправляет ничего.

Детская версия игры (Яндекс Игры) статистику не собирает совсем.

Privacy

Updated October 18, 2026

Anonymous statistics

The game sends the developer anonymous statistics to fix bugs and improve the game. What is sent:

  • session and shift length, where the player stops (menu, garage, mid-shift);
  • which in-game events happen and how they end (mini-games, errands, encounters), how the tutorial goes, in-game progress and purchases;
  • where in the game city crashes and failed shifts happen — roughly, in ~100-metre squares of the game map;
  • which screens are opened and which settings are changed;
  • errors, crashes and freezes of the game;
  • performance: frame and loading time, memory, graphics quality, device type (PC / Steam Deck / phone), operating system, GPU model, screen size, game language, game version.

What is not sent

Players are identified only by a random install number. Not sent: name, email, Steam ID, IP address, courier nickname, texts, save files. The developer cannot tell who you are.

Where it is stored

In Yandex Cloud (Russia), for at most one year, by the developer only; it is never shared or sold.

How to turn it off

Settings → Game → “anonymous statistics: off”. After that the game sends nothing.

The kids version of the game (Yandex Games) does not collect statistics at all.
